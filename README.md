# Photos

Trình xem và chỉnh sửa ảnh kiểu ChromeOS Gallery. Thiết kế Material 3 Expressive, Material Web Components (MWC), Material Symbols, Google Sans Flex.

- Xem ảnh, thu phóng, chuyển ảnh trong thư mục, thông tin và EXIF
- Cắt, xoay, lật, đổi kích thước, chỉnh ánh sáng và màu sắc, chú thích (bút, bút đánh dấu, tẩy)
- Hoàn tác / làm lại, Lưu, Lưu dưới dạng, In, Chia sẻ
- Cài được như PWA và mở ảnh từ app Tệp ("Mở bằng Photos")

Chạy thử: `python3 -m http.server` rồi mở `http://localhost:8000`. Không cần build.
`vendor/mwc.js` là bản đóng gói sẵn của `@material/web`.
